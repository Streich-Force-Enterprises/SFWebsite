4 · Gallery design (how photos get on the site)

  • One place, one entry per photo: file · caption · division · service line (fabrication, compactor chutes, structural, gates, fit-outs, maintenance) · month · featured. The build fails on a missing caption or an unknown service line, so a half-filed photo cannot ship.
  • Nobody hand-resizes. Originals go in src/assets/gallery/; Astro's built-in image service does the rest. A resized file in public/ is the thing to question in review.
  • Privacy by default: captions say what was built or fixed, never who for. No customer names, store numbers, addresses, chain signage, paperwork or faces unless you say yes for that photo.
  • Solutions is screenshots, not photos, always on demo data (never Loadstar's numbers).
  • Scale: the first batch is 12–20 photos. Adding the next batch is one file plus one entry each, no code.
